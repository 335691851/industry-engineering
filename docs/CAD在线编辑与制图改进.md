# CAD 在线编辑与制图改进

## 样例对齐

参照用户提供的《收卷轴-辊筒.pdf》，重点调整图面表达：纵向剖视占主体、长筒用断开画法、真实长度标注、两端加工深度、直径与公差直接标在视图上、倒角引出线、底部工序和标题栏。参考尺寸可使用括号；正负上下偏差成组排版。

断开画法只影响图纸空间的显示，DXF 模型空间仍保留 1:1 全长。未明确的几何特征不会因排版自动补齐。端部加工区由 machining_zones 给出，倒角由 chamfer_mm 给出；它们不是完整的实体特征建模系统。

图面使用独立 drawing_notes。review_items、推理过程和证据争议保留在业务数据及编辑区域，不再打印成制造图的正文。技术要求过长仍续页，网页按宽度显示并滚动阅读，避免把全部页面压缩到同一屏。

## 使用

生成图纸页 →「在线 CAD 编辑 / 加载 DWG」：

1. 打开当前生成的 DXF，或加载用户的 DWG / DXF。
2. 选择模型空间或某个图纸布局。滚轮缩放，平移工具拖动，支持端点和圆心捕捉。
3. 点击实体或从实体列表选择。直线可改端点、长度；圆可改圆心和半径；圆弧可改角度；无圆弧多段线可改宽高，其他多段线可改顶点；文字可编辑内容、位置和高度。
4. 新增直线、文字、水平/垂直尺寸；选中圆可以添加直径标注。尺寸工具依次选择两个测量点和标注位置。
5. 撤销/重做后，保存为当前图纸的新版本。原上传文件不覆盖。新结果重新进入图纸审核，下游工艺及关联上级同步失效。

尺寸显示文字可包含 `<>` 表示测量值。修改尺寸文字不等于修改几何。已有标注不会在几何变化后自动关联更新；需复核或重建。当前版本没有约束求解、修剪/延伸、块内编辑、三维实体建模及多用户协同。

## 实现

- 后端 `server/cad_editor.py`：ODA 将 DWG 读入 ezdxf 文档，保留原有图层、块、布局与未修改实体；只执行白名单编辑操作。SVG/PDF 预览来自 ezdxf 的同一渲染前端。
- 前端 `src/CadEditor.tsx`：SVG 画布、实体包围框命中、坐标转换、捕捉、数字属性、操作历史；服务器负责重新生成预览。
- 会话基于原始 source.dxf 加操作列表重放；SHA-256 校验会话源文件，保存时再校验业务对象 updated_at，避免覆盖并发修改。
- 保存生成独立版本的 DXF、PDF、SVG，并尝试输出 DWG。没有转换器时提供明确错误或仅输出可用格式。
- `geometry.cad_document` 为后端拥有的当前 CAD 版本引用。人工审核不会用旧参数化轮廓覆盖 CAD。生成工艺时优先读取已编辑 CAD 的 PDF 证据。
- CAD 实体修改不自动反算 geometry 参数；再次保存参数化尺寸或执行 Agent 重生成会创建新的参数化图纸。旧 CAD 文件仍作为历史版本保留。
- 图纸布局独立编辑，不自动同步模型空间。未支持的实体会保留；复杂外部参照、代理对象、缺失字体或图片资源仍可能无法完整显示。

主要 API：POST `/api/parts/{id}/cad/open`、`/upload`、`/{session}/preview`、`/{session}/save`。

实现参考：[ezdxf 原生尺寸标注](https://ezdxf.readthedocs.io/en/stable/tutorials/linear_dimension.html)、[ODA DWG 转换](https://ezdxf.readthedocs.io/en/stable/addons/odafc.html)。

本轮共 15 项测试通过，前端生产构建通过；DWG 经新增原生尺寸、保存和再次读取后仍保留该尺寸实体。
