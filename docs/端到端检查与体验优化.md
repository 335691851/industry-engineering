# 工程平台端到端检查与体验优化

## 本次完成的修改

1. 统一上下级解锁：参考输入、图纸、工艺均审核通过才算零件完成。复用零件的图纸失效时，其所有上级继续等待。
2. 增加完成数量与下一待办入口；MBOM 审核通过后定位可操作的最下级零件，再次进入零件时定位尚未完成的阶段。
3. 保存/归档/CAD 保存后的刷新保留当前预览，不再自动跳回相似图纸。项目切换使用请求序号防止旧响应覆盖新项目。
4. 修正检索到相似图纸却显示空页面的问题；默认展示已选择参考或首个候选。匹配分数标记为检索匹配度，不表示图纸已适用或尺寸已确认。
5. 编辑抽屉默认关闭，避免遮挡图纸。隐藏抽屉不接收键盘焦点；工具栏适应换行，输入区域加大。
6. 编辑未保存时展示提示，切换零件/项目及离开页面提供保护；CAD 入口要求先保存参数，避免两种编辑上下文互相覆盖。
7. 中文输入法组合输入按 Enter 不再发送消息；对话请求失败恢复输入内容。
8. 新增制造图预览缩放、适应窗口、打开 PDF、加载错误恢复。
9. CAD 支持 Ctrl/Cmd+S；保存后重新建立编辑基线，可以连续编辑与保存；关闭未修改的 CAD 不再弹出丢弃确认。
10. CAD 启动显示加载状态，超时可重试或退出。空布局保存返回可读的 422 提示，不再报 empty bounding box 的服务器异常。
11. 总装工艺重新生成之前保存编辑页工序内容，使编辑输入进入后续生成调用。

## 复现

```powershell
node --test tests/workflow.test.mjs
python -m pytest -q
npm run build
python launch_platform.py
```

打开 http://127.0.0.1:8000/ 。浏览器恢复可控制后，仍需进行从上传到归档的可视操作验收，尤其是 CAD 捕捉、标注和大文件性能。
